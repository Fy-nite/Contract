\section{Introduction}
\textbf{Contract} is a statically-typed language designed for deterministic
bytecode execution. Version 1.1 introduces a rigid type system, structured
type definitions, and first-class support for objects.

\section{Type System}
The type system is based on a registry of known types. Types must be declared
before they are referenced.

\subsection{Contracts}
Contracts are the main way of storing code.
similar to classes, Contracts define a "contract" with the runtime to state what you want the runtime to do.



\section{Object Instantiation}
Objects are instantiated using the \code{new} keyword. This allocates memory on the heap.

\begin{lstlisting}[style=contract, caption=Instantiation and usage]
fn main() {
    var p: Point = new Point();
    p.x = 10;
}
\end{lstlisting}

\section{Control Flow}
Contract supports standard imperative control flow structures.

\subsection{Conditional Statements}
\code{if-else} blocks are supported for conditional logic.

\subsection{Loops}
Loops are managed via \code{while} constructs.

\begin{lstlisting}[style=contract, caption=While loop]
while (counter > 0) {
    counter = counter - 1;
}
\end{lstlisting}

\section{Formal Grammar (EBNF)}
\begin{lstlisting}[basicstyle=\ttfamily\small]
TypesDecl      ::= 'Types' '{' TypeDefinition* '}'
TypeDefinition ::= 'type' IDENTIFIER '{' FieldDecl+ '}'
FieldDecl      ::= IDENTIFIER ':' IDENTIFIER ';'
NewExpr        ::= 'new' IDENTIFIER '(' ')'
IfStmt         ::= 'if' '(' Expression ')' Block ('else' Block)?
WhileStmt      ::= 'while' '(' Expression ')' Block
\end{lstlisting}
